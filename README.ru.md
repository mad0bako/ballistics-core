# ballistics — физическое ядро игры про оружейника

Ядро считает выстрел от химической формулы пороха до попадания в цель.
Ничего не «настраивается на глаз»: масса пули получается из чертежа и
плотности металлов, сила пороха — из элементного баланса и равновесия
продуктов горения, давление — из уравнения Резаля, прочность ствола —
из задачи Ламе, ресурс — из интеграла Дюамеля и корреляции износа.

Чистый Python, без зависимостей. Один выстрел со всеми последствиями
считается за 15-25 мс, так что ядро годится и для интерактивного подбора,
и для Монте-Карло на сотни выстрелов.

## Что именно моделируется

### Термохимия заряда (`thermochem.py`)

Игрок задаёт рецептуру в массовых долях. Дальше:

1. элементный баланс C, H, O, N на килограмм заряда;
2. равновесный состав продуктов в приближении пяти газов
   (CO₂, CO, H₂O, H₂, N₂) по реакции водяного газа
   `CO + H₂O ⇌ CO₂ + H₂`, при нехватке кислорода добавляется сажа,
   при избытке — свободный O₂;
3. теплота взрывчатого превращения при постоянном объёме
   `Qv = −[ΔH_реакции − Δn·R·T₀]`;
4. температура горения из энергетического баланса с поправкой на
   диссоциацию;
5. отсюда сила пороха `f = n·R·T₁`, показатель `k = 1 + R_уд/Cv_уд`,
   коволюм `α = Σ nᵢbᵢ`.

Расчёт самосогласованный: состав зависит от температуры, температура —
от состава, итерация сходится за десяток шагов.

Это тот узел, где живёт «соотношение окислителя и топлива». И он честно
показывает, почему наивная стратегия «добавь окислителя» не работает:
нитрат калия поднимает кислородный баланс и температуру пламени, но
уносит часть массы в конденсированный шлак, который газа не даёт, —
сила пороха при этом **падает**, а износ ствола растёт.

### Геометрия зерна (`grain.py`)

Функция формы `ψ(z) = κz(1 + λz + μz²)` не берётся из таблицы, а
считается точно из размеров зерна. Приём: объём зерна `V(e)` для всех
практических форм — полином не выше третьей степени, значит `ψ(z)` тоже
кубика, и её коэффициенты восстанавливаются по трём точкам. Одинаково
работает для шара, ленты, трубки и семиканального зерна.

Свод многоканального зерна выводится из гексагональной укладки:

```
e₁ = (D − (2m+1)·d) / (4(m+1)),   n = 3m² + 3m + 1
```

При m = 0 формула вырождается в трубчатую `(D−d)/4`, при m = 1 даёт
классическую семиканальную `(D−3d)/8`.

### Внутренняя баллистика (`interior.py`)

Классическая система (Серебряков, гл. 5; Corner, гл. 5):

```
dz/dt = u₁·p^ν / e₁                            закон горения Вьеля
ψ = ψ(z)                                       газообразование
φ·m·dv/dt = S·(p_дно − p_сопр)                 движение снаряда
p·W = f·ω·ψ − θ·(φ·m·v²/2 + Q_ст)              уравнение Резаля
W = W₀ − ω(1−ψ)/δ − α·ω·ψ + S·l                свободный объём
```

Распределение давления по каналу — лагранжево:

```
p_кн = p_дно·(1 + ω/(2φm))      нагружает затвор
p_ср = p_дно·(1 + ω/(3φm))      это видит датчик, к нему относятся SAAMI/CIP
p_дно                            разгоняет пулю
```

Интегратор — Кэш-Карп RK45 с контролем шага: артиллерийский выстрел
(20 мс) и пистолетный (0.3 мс) считаются одинаково устойчиво.

Теплоотдача в стенки считается по Дитрусу-Бёльтеру (Dittus-Boelter) отдельно средней по
каналу (для энергетического баланса) и у начала нарезов (для износа):
по Лагранжу скорость газа линейна вдоль канала, и начало нарезов
обдувается не так, как середина.

### Ствол (`barrel.py`)

Толстостенный цилиндр, критерий Мизеса. На внутренней поверхности:

```
σ_экв = √3·p·b² / (b² − a²)
p_упр = σ_т·(b² − a²) / (√3·b²)
p_разр = (2/√3)·σ_в·ln(b/a)
```

Автофретирование до радиуса ρ поднимает упругий предел до

```
p_авт = (2σ_т/√3)·[ln(ρ/a) + (b² − ρ²)/(2b²)]
```

Важное различие, которое модель держит явно: у боевых нарезных стволов
запас по **текучести** на самой поверхности канала штатно бывает около
единицы — первые выстрелы слегка наклёпывают внутренний слой, ствол сам
себя автофретирует и дальше работает упруго. Аварийным считается
исчерпание запаса по **разрушению**, и его держат не ниже 1.5–2.

Площадь канала считается с учётом нарезов: `S = πd²/4 + n·w·h`. Брать
просто площадь по полям — занизить силу на 2–4%.

### Пуля (`projectile.py`)

Тело вращения интегрируется численно, поэтому масса, центр масс и оба
момента инерции получаются из чертежа. Оболочечная пуля моделируется
слоями: у неё есть полый носик (свинец засыпается со стороны дна и до
острия не доходит) — без этого масса завышается процентов на пять.

Форм-фактор i₇ оценивается по обводам эмпирической зависимостью,
подобранной по четырём реальным пулям; если BC известен из отстрела,
его можно задать напрямую через `form_factor_override`.

### Износ ствола (`erosion.py`)

Три независимых механизма:

1. **Выгорание начала нарезов.** Температура поверхности за выстрел —
   точное решение для полубесконечного тела с переменным потоком
   (интеграл Дюамеля):
   `T_s(t) = T₀ + 1/√(πkρc) · ∫ q(τ)/√(t−τ) dτ`.
   Скорость уноса — корреляция Лоутона `w = A·∫exp(−B/T_s)dt`, умноженная
   на химическую агрессивность газов и стойкость материала поверхности.
   Тонкое покрытие теплофизически «прозрачно» (за 1 мс тепло проникает в
   сталь на ~110 мкм, а хром лежит слоем 25 мкм), поэтому активность
   поверхности берётся взвешенной по глубине проникновения. Ресурс
   считается в две фазы: пока покрытие цело — по его стойкости, после
   износа насквозь — по подложке. Поэтому хромирование даёт выигрыш
   в разы, а не в десятки раз.
2. **Малоцикловая усталость казённой части** по Мэнсону-Коффину.
3. **Механический износ полей** ведущим пояском.

### Внешняя баллистика (`exterior.py`)

Точечная модель 3-DOF: сопротивление по стандартным функциям G1/G7,
масштабированным форм-фактором, гравитация, Кориолис, ветер, деривация.
Атмосфера — МСА с поправкой на влажность (влажный воздух легче сухого).
Гироскопическая устойчивость считается и аэродинамически, и по правилу
Миллера.

### Допуски и кучность (`tolerances.py`)

Кучность не «характеристика оружия», а сумма физических вкладов:

- разброс дульной скорости → вертикаль (Монте-Карло через настоящую
  внутреннюю баллистику, а не «плюс-минус 10 м/с»);
- боковой сброс от дисбаланса пули: `θ = ε·ω/V` — смещение центра масс
  на 10 мкм при 6000 рад/с и 800 м/с даёт 0.26 МОА, больше остального
  бюджета вместе взятого;
- аэродинамический подскок от несоосности пули в патроне;
- колебания ствола: время вылета гуляет вместе со скоростью и попадает
  в разную фазу изгибных колебаний;
- множитель износа.

### Мастерская (`workshop.py`)

Игровой слой не выдумывает физики. Он превращает станочный парк и навык
в допуски, которые дальше честно прогоняются через Монте-Карло:

```
станок + навык → допуск → разброс скоростей → кучность
станок + навык → чистота канала → износ → ресурс ствола
```

Плюс технологические ограничения: без гальванической ванны канал не
хромировать, слой хрома толще 60 мкм не держится, автофретирование
требует дорнирующего пресса.

## Сверка с реальностью

Модель проверяется не на себе, а на независимо известных величинах.
Все проверки собраны в `tests/test_physics.py`.

**Пороха** — три реперных состава попадают в справочные вилки
одновременно по четырём параметрам:

| | f, кДж/кг | T₁, К | k | α, дм³/кг |
|---|---|---|---|---|
| одноосновный | 986 (950–1000) | 2879 (2800–3000) | 1.248 (1.21–1.26) | 1.045 (0.95–1.10) |
| двухосновный | 1053 (1000–1150) | 3285 (3200–3400) | 1.218 | 0.985 |
| трёхосновный | 1028 (1050–1150) | 3002 (2800–3000) | 1.240 | 1.039 |

**Функция формы** — совпадает с таблицами Серебрякова: шар даёт ровно
κ=3, λ=−1, μ=1/3; трубка 1.045 / −0.043 / 0; семиканальное зерно
0.771 / +0.147 / −0.034 при ψ₁=0.859.

**Пули** — масса из чертежа против каталога: матчевая .308 168 гран
11.01 г против 10.89 (+1.1%), 9×19 124 грана 8.02 против 8.03 (−0.1%),
.338 250 гран 16.34 против 16.2 (+0.8%). BC(G7) матчевой .308 — 0.224
при каталожных 0.224.

**Внутренняя баллистика** — пять систем от пистолета до гаубицы. Порядок
проверки строгий: свод зерна подбирается так, чтобы при **паспортной
навеске** получалось **паспортное давление**, после чего дульная скорость
уже не подгоняется — она предсказывается, и по ней модель и проверяется.

| патрон | навеска | v₀ расчёт | v₀ паспорт | откл. | p расчёт | p паспорт | откл. |
|---|---|---|---|---|---|---|---|
| 9×19 | 0.40 г | 358 м/с | 360 м/с | −0.5% | 237 МПа | 235 МПа | +0.9% |
| 7.62×51 | 2.85 г | 804 м/с | 810 м/с | −0.7% | 418 МПа | 415 МПа | +0.7% |
| 152 мм | 7.0 кг | 659 м/с | 655 м/с | +0.5% | 307 МПа | 300 МПа | +2.3% |
| .338 LM | 6.30 г | 892 м/с | 890 м/с | +0.2% | 471 МПа | 420 МПа | +12% |
| 5.56×45 | 1.64 г | 877 м/с | 940 м/с | −6.7% | 398 МПа | 430 МПа | −7.5% |

Три системы из пяти сходятся в пределах процента одновременно по скорости
и по давлению. Два выброса — .338 LM и 5.56 — это цельно один и тот же
эффект: обе системы работают на предельной плотности заряжания (заряд
занимает всю камору), а именно там уравнение Нобеля-Абеля становится
слишком жёстким и загоняет давление в предел раньше времени. У .338
скорость при этом всё равно точна, промахивается только пик.

**Внешняя баллистика** — сверка с таблицей для .308 175 гран
(790 м/с, BC G7 = 0.243) на 1000 м:

| | расчёт | таблица |
|---|---|---|
| время полёта | 1.729 с | 1.73 с |
| скорость у цели | 424 м/с | ~420 м/с |
| понижение | 12.03 м | 11.9–12.1 м |
| деривация | 0.35 м | ~0.3 м |

**Ресурс ствола** — 12 200 выстрелов для .308 (реально 10–15 тыс.),
709 для горячего двухосновного магнума (реально 1.5–2 тыс.), 28 100 для
охлаждённого оксамидом. Хром 25 мкм даёт 1.7×, 50 мкм — 2.9× (реально
2–3×).

## Где модель заведомо приблизительна

Честный список, чтобы не принимать удобные числа за истину:

- **Диссоциация продуктов горения** учтена сосредоточенной поправкой с
  двумя калибровочными константами, а не полным равновесием с радикалами
  (OH, H, O, NO). На реперных порохах это даёт правильные T₁ и f, но на
  экзотических составах может уехать.
- **Скорость горения** оценивается из энергетики состава эмпирической
  связью `u₁ ~ (f/f_ref)³` с модификаторами по компонентам. Реальная
  скорость горения зависит ещё и от структуры к-фазы, которую состав не
  задаёт однозначно.
- **Константа износа** откалибрована по одной реперной точке (.308-класс
  ~0.02 мкм/выстрел). Порядок величины и все тренды верны, абсолютное
  число — с точностью до множителя.
- **Форм-фактор по обводам** — 5–10%, на нетиповых формах хуже.
- **Деривация** взята эмпирикой Литца; строго она требует 6-DOF.
- **Давление форсирования** — лумпед-параметр (натяг дульца плюс
  врезание). Модель кладёт его в реальные 30–50 МПа для винтовок, но
  раскладка между слагаемыми условна.
- **Модель одномерная**: никаких прорывов газа мимо пули, перекоса
  снаряда в канале и неравномерного воспламенения по длине заряда.
- **Уравнение состояния Нобеля-Абеля** `p(W − αω) = ωRT` — главный
  источник систематической ошибки на краю диапазона. Оно хорошо работает
  до плотности заряжания около 0.8-0.9 г/см³, а выше становится слишком
  жёстким: свободный объём в знаменателе схлопывается быстрее, чем на
  самом деле, и модель раньше времени упирается в предел давления. Это
  ровно то, что видно на 5.56 и .338 LM в таблице сверки. Замена на
  вириальное уравнение состояния — самая осмысленная следующая доработка.

## Структура

Каждый слой зависит только от нижних, так что любой можно заменить
целиком, не трогая остальные.

```
units, materials       константы, единицы, свойства металлов
   ↓
thermochem             состав → f, T₁, k, коволюм, состав газов
grain                  геометрия зерна → ψ(z)
   ↓
propellant             порох = термохимия + зерно + закон горения
   ↓
interior               основная задача внутренней баллистики
   ↓
barrel, projectile, cartridge, erosion, exterior
   ↓
tolerances, simulation
   ↓
design, workshop       обратные задачи и игровой слой
```

## Единицы

Внутри ядра всё строго в СИ: метры, килограммы, секунды, паскали,
кельвины. Перевод в оружейные единицы (миллиметры, граны, футы в
секунду, МОА) — только на границе, в `units.py`. Это избавляет от
классической ошибки смешения систем, из-за которой в баллистических
расчётах регулярно теряется множитель 10⁶.
